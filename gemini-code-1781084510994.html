📌 프로젝트 개요

목적

피아노 학습자가 자신의 연주를 즉시 분석받고 구체적인 피드백을 받을 수 있는 시스템 개발

핵심 기능

  • 악보 분석 : MusicXML 파일에서 정확한 음표 추출
  • 음성 인식 : WAV 파일에서 연주한 음정과 타이밍 추출
  • 자동 채점 : 악보와 연주 비교분석 (정확도, 누락, 박자)
  • AI 피드백 : GPT-4o를 활용한 맞춤형 평가

🛠️ 기술 스택

프론트엔드: React 18 + Vite + PWA (모바일 앱처럼 설치 가능)
백엔드: Go 1.24 (고성능 HTTP 서버)
음악 분석: Python 3.10 + music21 + piano_transcription_inference
AI 피드백: OpenAI GPT-4o-mini + SSE 스트리밍
상태 저장: localStorage (기록) + sync.Map (session, TTL 5분)
배포: Netlify (PWA) + Render (백엔드) 또는 단일 Go 서버

🏗️ 상세 시스템 흐름

① PWA (React)

악보(MusicXML) + 연주 음원(WAV) → POST /api/analyze

② Go 백엔드 (HTTP Server)

파일 수신 → Python subprocess 실행 → session_id 생성

③ Python 파이프라인

Module1 (음표 추출) → Module2 (음성 인식) → Module3 (채점)

④ 결과 전달 & GPT 피드백

즉시: 점수/등급 표시 | 실시간: SSE 스트리밍으로 AI 피드백 전송

⭐ 주요 기능

📊 실시간 채점

연주 분석 후 즉시 점수와 등급 표시 (A+부터 C까지 7단계)

🎯 정밀 분석

🤖 AI 피드백

GPT 기반 구체적 평가와 개선 팁 제공 (한국어/영어/일본어/중국어)

📈 학습 기록

연습 히스토리, 점수 추이, 요일별 통계 자동 저장

💡 사용 방법

  1. 분석 탭으로 이동

    MusicXML 악보 파일과 WAV 연주 음원 업로드

  2. 피드백 언어 선택 (한국어/English/日本語/中文)

    원하는 언어로 피드백 수신

  3. 분석 시작 클릭

    2~5초 내 점수 표시

  4. 피드백 확인

    진행 바 → AI 피드백 카드 (실시간 스트리밍)
