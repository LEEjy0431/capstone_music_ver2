기획 동기 및 필요성

기존 방식의 한계

  • 반복적인 개인 연습에 의존 — 객관적 오류 분석 및 피드백 시스템 부족
  • 초보 연주자는 음정·박자 오류를 스스로 인지하기 어려움
  • 전문 레슨은 비용 및 시간의 제약 존재

본 과제의 목표

딥러닝 기반 음원 분석 기술을 활용하여 사용자의 연주 데이터를 자동 분석하고, 악보와 비교하여 오류를 검출하며 맞춤형 피드백을 제공하는 시스템 개발

기술 스택 & 시스템 아키텍처

기술 스택

프론트엔드: React 19 + Vite (모바일 퍼스트 웹앱)
백엔드: Go 1.24 (Go 표준 라이브러리 경량 HTTP 서버)
음악 분석: Python 3.10 + music21 + piano-transcription-inference (PyTorch)
AI 피드백: Ollama — Qwen 2.5-1.5B Instruct (로컬 LLM)
상태 저장: localStorage + sync.Map (TTL 5분)

Python 분석 파이프라인

Module 1 — 악보 파싱

music21 라이브러리로 MusicXML 파싱

정답 음표 추출: 음정, 시작/종료 시간, 속도

Module 2 — 음원 인식

piano-transcription-inference 딥러닝 모델로 WAV 분석

PyTorch 기반 / BPM에 맞춰 타임 퀀타이즈 수행

Module 3 — 비교 & 채점

정답 음표 vs 연주 음표 비교 채점

화음 그룹 매칭 / 타이밍 오차 허용 (±0.2초)
누락·오타·추가 음표 구분 → 0~100점 산출

Module 4 — AI 피드백

Ollama — Qwen 2.5-1.5B Instruct (로컬 LLM)

채점 결과 기반 음정·리듬·타이밍 항목별 피드백 및 개선 팁 생성

주요 기능 — 자동 채점 & 항목별 분석

자동 채점 & 항목별 분석
