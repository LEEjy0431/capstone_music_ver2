🏗️ 시스템 개요

시스템은 세 가지 구성 요소로 이루어져 있습니다.

① Python 분석 파이프라인 악보·음원 → 음표 추출 → 비교·채점 (핵심 엔진)
② Go 백엔드 서버 Python 실행 · session 관리 · AI 피드백 SSE 스트리밍
③ React PWA 프론트엔드 파일 업로드 · 결과 시각화 · 모바일 홈 화면 설치 지원
📡 전체 흐름 파일 업로드 → 채점 결과 즉시 표시 → AI 피드백 실시간 스트리밍

🏗️ 아키텍처 흐름

① POST /api/analyze PWA → 악보(XML/PDF/이미지) + 연주(WAV) 전송
② Go 백엔드 수신 파일 임시 저장 → Python subprocess 실행
③ Python 파이프라인 실행 (최대 20분, CPU 기준) Module1 (악보 파싱) → Module2 (음표 추출) → Module3 (채점) → chord_upgrade (화음 재검증)
④ 결과 반환 + session_id 발급 점수·등급 즉시 표시 → GET /api/feedback/stream?session_id=... 로 AI 피드백 SSE 수신

🔄 Python 파이프라인 (2/2) — 화음 재검증

chord_upgrade.py — CQT 기반 화음 재검증 채점(Module3)에서 누락(missed)으로 분류된 음표를 librosa CQT(Constant-Q Transform)로 재확인

왜 필요한가?

피아노 화음은 여러 음이 동시에 울림
모델이 화음 구성음 일부를 놓치는 경우 발생
→ 점수 과소 평가 문제

어떻게 동작하나?

오디오 전체의 CQT 에너지 계산
누락 음표 시간대 해당 주파수 에너지 검사
에너지 기준 충족 시 → 정답으로 구제

결과 꾸밈음 제거(Module1) + 화음 재검증(chord_upgrade) 조합으로 채점 정확도 대폭 향상
